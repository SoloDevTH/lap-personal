Lap Personal Edition `0.3.2-personal.13` is an unofficial build of [Lap](https://github.com/julyx10/lap) by julyx10. It is Windows-only and tuned for very large libraries.

### Changes
- Deleting moves files to the Recycle Bin in batches, shows progress, and always closes the dialog. Deleted photos disappear from the grid without a page reload.
- Files on a drive that is not connected are no longer treated as deleted.
- Selecting many photos and loading thumbnails no longer freezes the window.
- Folder sync is faster, duplicate scan is faster, and removing an album keeps the app responsive.
- Scan progress no longer gets stuck near 100%.
- Background work runs at below-normal priority and uses about half of the CPU.

See the [README](https://github.com/SoloDevTH/lap-personal#changes-from-upstream-lap) for the full list.

### Install
Download `Lap_0.3.2-personal.13_x64_en-US.msi`, close Lap, and run the installer. The installer is unsigned, so if SmartScreen warns you, choose **More info → Run anyway**. Installing replaces official Lap and keeps your library. Auto-update is disabled.
